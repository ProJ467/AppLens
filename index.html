AppLens

Welcome to AppLens!

AppLens is a Windows application inspector that scans visible windows and shows details like title, process, PID, position, size, and executable path.

Use it to explore open windows on your system and copy window information to the clipboard.

You must have Python 3.6 or higher installed.

Download the AppLens.py file, then run it with python AppLens.py or double-click the downloaded file.
